# 삿포로 스시 취소표 텔레그램 알림 (미야카와 + 카이)

공식 사이트 달력(`src/calendar.json`)을 **1분마다** 확인해서
**2026-12-21 / 12-22 / 12-23** 중 하루에 `空有り`(빈자리)가 뜨면 텔레그램으로 알려줍니다.
스시 카이는 TableCheck 빈자리 조회로 **12-21 / 12-22**에 2명 자리가 생기면 알려줍니다.
GitHub Actions에서 돌기 때문에 내 PC를 꺼 둬도 계속 확인합니다.

## 설정 (15분 정도)

### 1) 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 이름과 아이디 입력
2. 마지막에 나오는 **토큰**(`123456789:ABC...` 형태)을 복사해 둡니다.
3. 방금 만든 봇과 대화를 열고 아무 메시지(예: `hi`)나 보냅니다.
4. 브라우저 주소창에 `https://api.telegram.org/bot<토큰>/getUpdates` 를 입력해 엽니다.
   결과에서 `"chat":{"id": 123456789` 부분의 숫자가 **chat id**입니다.

### 2) GitHub 저장소 만들기
1. GitHub에서 새 저장소를 만듭니다. **Public으로 만드세요.**
   (Private 저장소는 무료 실행 시간이 월 2,000분이라 계속 도는 이 방식은 금방 한도를 넘습니다.
   토큰은 아래 Secrets에 들어가기 때문에 Public이어도 외부에 보이지 않습니다.)
2. 이 폴더의 파일을 그대로 올립니다. `.github/workflows/watch.yml` 경로를 꼭 유지하세요.
   - `monitor.py`
   - `.github/workflows/watch.yml`
   - `README.md`

### 3) 비밀값 등록
저장소 → **Settings → Secrets and variables → Actions → New repository secret**
- `TELEGRAM_BOT_TOKEN` = 1)에서 받은 토큰
- `TELEGRAM_CHAT_ID` = 1)에서 찾은 숫자

### 4) 테스트
저장소 → **Actions** 탭 → (처음이면 워크플로 사용 허용) → **Sushi cancel watch** → **Run workflow**
→ 몇십 초 뒤 텔레그램에 "✅ 연결 테스트" 메시지와 세 날짜의 현재 상태가 오면 설정이 끝난 겁니다.
그다음부터는 1분마다 자동으로 확인합니다. Actions 탭에 실행 하나가 계속 '진행 중'으로 보이는 게 정상입니다.

## 알림 종류
- 🍣 **빈자리 발생**: 해당 날짜에 `空有り` 표시가 생기면 바로 알림 (전화번호 포함)
- ⌛ **빈자리 사라짐**: 표시가 없어지면 알림 (다시 생기면 또 알림)
- ℹ️ **휴무로 변경**: 대상 날짜가 임시휴무 등으로 바뀌면 알림

## 참고
- 실행 하나가 약 5시간 50분 동안 1분마다 확인하고 끝나면, 대기 중이던 다음 실행이 이어받습니다. 교대할 때 1~2분 정도 빌 수 있습니다.
- 확인 간격은 `watch.yml`의 `INTERVAL_SECONDS`로 바꿀 수 있습니다. 사이트에 부담을 주지 않도록 60초 미만은 권하지 않습니다.
- 달력 확인이 10번 연속 실패하면 텔레그램으로 경고가 갑니다.
- 날짜를 바꾸려면 `watch.yml`의 `MIYAKAWA_DATES`, `KAI_DATES`를 고치면 됩니다. 인원은 `KAI_PEOPLE`.
- 12/23이 지나면 스크립트가 알아서 아무것도 하지 않습니다. Actions에서 워크플로를 꺼도 됩니다.
- 사이트 구조가 바뀌어 확인에 실패하면 실행이 실패로 표시되고 GitHub이 이메일로 알려줍니다.
